## 확인한 범위

## 출처와 미확인 사항

- 제공 HWP의 SHA-256: `f1ffda8b16288568556210189a53042fc905cdf334d83a0f821d08ca6803db1b`. 본문의 데이터셋 구성과 삽입 `BIN0002` CSV 예시를 확인했다. 작성·제출 안내문은 개발 지시로 취급하지 않았다.
- 추출된 `지식성분데이터.xlsx`는 성분 지식용 단일 시트다. 정확한 코드 토큰 검색에서 위 코드의 정의를 찾지 못했다.

- `VP`/`NVP`의 풀네임, `P0`~`P2`·`W0`~`W2`의 등급 경계, 나머지 코드의 정확한 정의, 평가자·평가 절차, 상·중·하 이미지 간 라벨 적합성은 **미확인**이다. 약자를 풀어 진단명·정상/이상·위험도·효능으로 번역하지 않는다.
- JSONL의 설문 ID·이미지명과 CSV/JPG 사이의 개별 연결은 확인되지 않았다. 번호·파일명·고민 폴더로 조인을 추측하지 않는다. 이번 입력 전달은 그러한 조인이나 새로운 멀티모달 학습을 하지 않는다.

## 실험용 연결 원칙

구현 계약은 `aihub71886-source-codes-v1`이다. 추천 JSONL 9,000건의 문자열은 모두 위 순서의 8개 코드를 가지며, 전체 관측 조합은 149개다. 원천 지문을 기존 매니페스트와 대조한 후 보존된 TRAIN 프로필 4,824개에서 증명되는 **145개 조합**만 지원 파일에 포함했다. 각 조합의 최소 비공개 특징 근거는 원래 프로필 해시와 특징 벡터에 일치해야 한다. 검증 분할이나 해시 슬롯 일치만으로 새 조합을 허용하지 않는다. 지원 파일은 원본·매니페스트·가중치와 별도로 개인 ML 폴더에 저장하며 API·DB로 보내지 않는다.

사진 분류기의 8개 출력을 위 순서의 **불투명한 원천 코드**로만 묶어 추천 모델의 `initial_skin_condition` 입력에 전달할 수 있다. 이는 검증된 임상 해석이 아니라 명시적으로 버전을 관리하는 구조 호환 정책이다. 모델이 실제 학습에서 지원한 입력인지 확인하고, 지원되지 않는 조합은 설문 입력만 사용하는 경로로 처리하며 그 이유를 표시한다. 누락된 인구통계·환경 값이나 새로운 피부 고민을 사진 코드에서 만들어 넣지 않는다.

사진 코드가 성분 후보의 상대 순위에 영향을 줄 수 있어도, 원천 추천 답변의 성분 언급을 학습한 모델은 효능·농도·알레르기 안전성을 증명하지 않는다. 승인된 매장 정책, 등록된 전성분, 제외 성분, 매장 범위, 공개 상태와 재고 필터를 계속 적용한다. 사진 분류 확률을 임상 확률·심각도나 제품 효과 점수로 사용하지 않는다.

구조적 호환성 확인과 서비스 연결 검사는 추천 품질의 검증을 대신하지 않는다. 실제 사진 → 상태 코드 → 성분 후보 → 매장 제품의 전체 경로는 별도의 사람 단위 분리 평가, 촬영 품질·지역 적합성 확인, 성분 추천 검수와 현장 검증이 필요하다. 그 전에는 실험용 표시를 유지한다.
