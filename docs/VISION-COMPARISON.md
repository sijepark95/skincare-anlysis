# ConvNeXt와 OpenAI 사진 분석 비교 가이드

현재는 **평가 사진이 없는 준비 단계**입니다. 새 사진을 전송하거나 실제 OpenAI 이미지 요청을 실행하지 않았습니다. 이 도구는 키오스크와 분리된 연구 명령이며, 결과를 성분·매장 제품 추천에 연결하거나 운영 모델을 자동으로 교체하지 않습니다.

## 1. 이번 비교에서 알 수 있는 것

| 대상                             | 출력                                                        | 우선 확인할 내용                                                           |
| -------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------- |
| 저장된 ConvNeXt-Tiny             | 기존 8개 항목의 원본 코드                                   | 처리 가능 여부, 시간, 같은 참여자의 반복 촬영에서 코드 변화                |
| OpenAI `gpt-4.1-mini-2025-04-14` | 눈에 보이는 붉은 기, 반점, 모공, 잔주름, 각질의 제한된 관찰 | 완료·거절·실패·판단 불가, 시간, 실제 사용 토큰과 비용 추정, 반복 관찰 변화 |

OpenAI의 각 관찰은 `visible`(보임), `not_visible`(이 사진에서 보이지 않음), `uncertain`(불확실), `not_assessable`(판단 불가) 중 하나입니다. 이 값은 중증도 순서가 아니며, “보이지 않음”이 해당 상태가 없다는 뜻도 아닙니다. 수분, 장벽 건강, 민감성, 질환, 성분 효능·안전성은 이 사진 평가의 측정 대상이 아닙니다.

**두 출력의 라벨 정의가 아직 같지 않습니다.** 원본 NS/S, P0/P1/P2 등의 의미·평가 기준이 확인되기 전에는 ChatGPT 관찰을 해당 코드로 바꾸지 않습니다. 일치율을 정확도로 부르거나 우승 모델을 정하지 않습니다. 기존 123장 검증 자료는 모델 선택에 사용했으므로 독립 테스트가 아닙니다.

선택한 OpenAI 모델은 이미지 입력과 구조화 출력을 지원합니다. 구조가 올바르다는 사실은 관찰이 정확하다는 증거가 아닙니다. [모델 문서](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [이미지 입력 안내](https://developers.openai.com/api/docs/guides/images-vision), [구조화 출력 안내](https://developers.openai.com/api/docs/guides/structured-outputs)를 참고하세요.

## 2. 사진을 준비하기 전에

새로운 **성인 자원자**에게 다음 내용을 알리고 별도의 외부 사진 처리 동의를 받으세요. 기존 키오스크의 성분 설명 동의는 사진 전송 동의가 아닙니다. 아래는 운영 준비용 안내이며 완성된 법률 검토 문서가 아닙니다.

- 목적: 두 실험 방식의 육안 관찰·처리 성능 비교. 진단이나 치료·효능 검증이 아닙니다.
- 전송처·내용: OpenAI API에 메타데이터를 제거한 얼굴 사진 한 장. 이름, 참여자 코드, 파일명, 설문, 기존 모델 코드, 매장·제품 정보는 전송하지 않습니다. 얼굴 사진 자체로 개인을 알아볼 수 있으므로 익명 데이터라고 안내하지 마세요.
- 보관: 참여자가 동의한 만료일까지 비공개 PC 폴더에 사진과 실험 결과를 관리합니다. 도구는 정제 사진을 추가 저장하지 않으며, 원본은 운영자가 직접 넣고 삭제합니다. 외부 처리와 로컬 결과 보관을 각각 확인합니다.
- 외부 보관: 요청에 `store:false`를 사용하지만 기본적인 API 악용 감시 기록은 최대 30일 보관될 수 있습니다. 이것은 무보관 설정이 아닙니다. 로컬 삭제가 제공업체 보관 데이터의 삭제까지 보장하지 않습니다. API 데이터는 별도 참여 설정이 없는 한 모델 학습에 사용되지 않습니다. [OpenAI 데이터 처리 안내](https://developers.openai.com/api/docs/guides/your-data)를 확인하세요.
- 선택·철회: 참여하지 않아도 서비스 이용에 불이익이 없으며, 철회하면 새 전송 시도를 막고 로컬 결과를 삭제합니다. 이미 시작되거나 전송 절차에 들어간 요청을 취소하거나 외부의 모든 기록을 즉시 회수할 수 있다고 약속하지 마세요.

실제 동의 증빙과 참여자 코드의 연결은 별도의 비공개 보관 장소에서 관리하세요. 코드 파일에는 이름·연락처·병력·서명 원문을 넣지 않습니다. 체크값은 운영자의 기록이며 실제 증빙이나 신원·나이·이용 허가를 독립적으로 검증하지 않습니다.

AI-Hub 원본, 다른 라이선스 자료, 기존 학습·검증 사진, 키오스크 고객 사진과 미성년자 사진은 이 파일럿에 넣지 않습니다. **각 사진에는 동의한 성인 한 명만 포함해야 하며 다른 사람, 콜라주, 이름 등 식별 문구가 있으면 안 됩니다.** 운영자가 전송 전에 직접 확인해야 합니다. Python 비교 도구는 얼굴 수나 동의자의 신원을 확인하지 않으며 OpenAI의 여러 얼굴 관찰은 이미 전송한 이후의 결과입니다. 학습·상업 이용 허가가 외부 전송 동의를 대신하지 않습니다. 도구는 등록된 원본 경로와 준비된 학습 목록의 동일 바이트 해시를 차단하지만, 모든 원천 이미지·근접 중복·동일인을 찾아내지는 못합니다.

## 3. 빈 평가 폴더 만들기

PowerShell이 어느 폴더에 있어도 전체 경로 명령을 사용할 수 있습니다. 기존 이름은 덮어쓰지 않습니다.

```powershell
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-init --name vision-pilot-001
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-check --name vision-pilot-001
```

실제 저장 위치는 프로젝트의 `.local/ml-workspace.json`에 지정된 **OneDrive 밖의 비공개 ML 폴더** 아래 `comparisons\vision-pilot-001`입니다. 사진이 없는 현재 상태의 정상 응답은 `needs_photos`, `photo_count: 0`입니다. API 키, 모델, 사진 디코더나 네트워크를 사용하지 않습니다. 기본 로컬 만료는 생성 후 14일이며 최대 30일입니다. 준비 중 만료됐다면 새 평가 이름으로 시작하세요.

| 파일/폴더               | 운영자 작업                                                               |
| ----------------------- | ------------------------------------------------------------------------- |
| `NOTICE.txt`            | 전송·보관·실험 한계를 확인                                                |
| `images/`               | 동의받은 평가 원본만 직접 배치; 도구가 폴더에서 사진을 자동 수집하지 않음 |
| `manifest.json`         | 실제로 사용할 사진의 명시적인 목록과 SHA256 기록                          |
| `consent-template.json` | 모든 동의 항목이 꺼진 참고 양식; 동의 증빙 확인 후 값 입력                |
| `consents.json`         | 참여자별 실제 동의 기록; 처음에는 비어 있음                               |

## 4. 동의 기록과 사진 목록 입력

참여자 한 명의 여러 촬영은 동일한 `participant_group`을 사용합니다. 실제 인물 정보 대신 무작위 16자리 소문자 16진수 ID를 사용하세요. 사진은 `e-…`, 참여자는 `p-…`, 동의는 `c-…` 형식입니다. 사진 파일명도 사진 ID와 같게 만듭니다. 영문 이름이나 생년월일을 사용하지 않습니다.

예를 들어 ID를 생성하려면 다음 명령을 **각각 새로 실행**하세요. 아래 문자열 접두사는 용도에 맞게 바꿉니다.

```powershell
'e-' + [guid]::NewGuid().ToString('N').Substring(0, 16)
'p-' + [guid]::NewGuid().ToString('N').Substring(0, 16)
'c-' + [guid]::NewGuid().ToString('N').Substring(0, 16)
```

`manifest.json`의 기존 평가·생성·만료 필드는 보존하고 `photos`에 다음 형태를 추가합니다. 아래 ID는 설명용이며 새 ID와 실제 해시로 바꾸세요.

```json
{
  "photo_id": "e-1a2b3c4d5e6f7890",
  "participant_group": "p-1122334455667788",
  "file": "images/e-1a2b3c4d5e6f7890.jpg",
  "sha256": "실제 파일의 소문자 SHA256 64자리",
  "consent_id": "c-8877665544332211"
}
```

정확한 사진 파일 경로를 지정해 해시만 확인합니다. 폴더 전체를 검색하거나 학습 폴더를 지정하지 마세요.

```powershell
(Get-FileHash -LiteralPath '비공개 평가 폴더\images\e-1a2b3c4d5e6f7890.jpg' -Algorithm SHA256).Hash.ToLowerInvariant()
```

`consents.json`의 `participants` 배열에는 동의 증빙을 확인한 참여자의 기록을 넣습니다. `consent-template.json`을 복사하되 **실제 확인하지 않은 값을 true로 바꾸지 마세요.** `adult`, `external_processing`, `local_results_storage`, `independent_from_training`, `not_aihub_or_other_licensed_source`, `single_subject_images`가 모두 실제로 확인돼야 합니다. `single_subject_images`는 해당 참여자의 모든 등록 사진이 앞서 설명한 한 사람·식별 문구 없는 조건을 충족한다는 운영자 확인입니다. `notice_version`은 생성된 값 그대로 사용합니다.

`accepted_at`은 실제 동의 시각, `expires_at`은 동의한 만료 시각을 UTC ISO 형식으로 입력합니다(예: `2026-10-12T10:00:00+00:00`). 만료는 동의 후 30일 이내이며 평가의 로컬 만료보다 빠르면 안 됩니다. `revoked_at`은 처음에는 `null`, 철회 시에는 실제 철회 시각입니다. 사용하지 않는 동의 기록과 동일 사진 중복은 거부됩니다.

먼저 다음 검사를 반복해서 완료하세요. **사진이 등록된 경우 검사 명령은 목록의 사진 바이트를 읽어 해시를 확인하지만 디코딩·전송은 하지 않습니다.**

```powershell
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-check --name vision-pilot-001
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-run --name vision-pilot-001 --comparison-run paired-001
```

두 번째 명령도 기본은 모의 실행입니다. `--send-to-openai`가 없으면 모델·키·네트워크를 사용하지 않습니다. 실제 요청 전 모든 사진의 동의·경로·해시·학습 중복·횟수 한도를 검사합니다.

## 5. 동의 사진이 준비된 후에만 실제 비교

첫 운영 확인은 예를 들어 5명에게서 정상 조명 촬영, 같은 조건 재촬영, 미리 정한 조명 변화 촬영을 한 장씩 받아 총 15장으로 시작할 수 있습니다. 이는 절차 확인용 예시이며 정확도를 입증할 표본 수가 아닙니다. 과도한 화장·필터·조명·가림과 기기/촬영 조건은 별도 비공개 촬영 기록에 남기세요. 모델이 추정한 나이·성별·인종을 기록하지 않습니다.

아래는 **미래의 실제 유료 전송 명령**입니다. 현재는 실행하지 않았습니다. 기존 `.env.local`의 `OPENAI_API_KEY`만 명시적으로 읽으며 채팅이나 출력에 표시하지 않습니다. 기본 한도는 20회, 명시 가능한 최대 한도는 100회입니다. 사진 수 전체가 한도 안에 있어야 시작합니다.

```powershell
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-run --name vision-pilot-001 --comparison-run paired-001 --manifest skin-all-001 --model-run skin-all-head-001 --device cpu --max-api-calls 20 --send-to-openai --openai-env-file "C:\Projects\AELUNE\.env.local"
```

운영 키오스크와 GPU를 동시에 경쟁하지 않도록 예시는 CPU로 설정했습니다. 저장된 가중치만 읽으며 학습이나 가중치 다운로드를 하지 않습니다. 사진은 메모리에서 방향 보정·RGB 변환·메타데이터 제거 후 최대 긴 변 1536px의 JPEG로 정제합니다. 두 방식에 **같은 JPEG 바이트**를 주지만 ConvNeXt는 내부적으로 짧은 변 236px 재조정과 224px 중앙 자르기를 수행하고, OpenAI의 내부 처리는 다릅니다. 같은 입력 텐서나 모든 얼굴 영역을 동일하게 봤다고 주장할 수 없습니다.

API는 고정된 HTTPS Responses 주소, 고정 모델·프롬프트·엄격한 관찰 스키마, `store:false`, 한 번의 요청, 제한된 응답 크기를 사용합니다. 30초 네트워크 타임아웃/기한을 설정하지만 DNS 등의 처리까지 포함한 강제 프로세스 종료 시간을 보장하지 않습니다. 리디렉션·도구·대화 기록·자동 재시도는 사용하지 않습니다.

외부 요청 직전에 `attempts.jsonl`을 디스크에 기록합니다. 중단되면 응답을 못 받았어도 제공업체가 처리했거나 비용이 발생했을 수 있습니다. 같은 실행 이름으로 재개·덮어쓰기는 금지됩니다. 새로운 실행 이름을 선택하면 새 유료 평가가 되므로 기존 기록과 제공업체 사용량을 먼저 확인하세요. 횟수 한도는 실행별 한도이며 계정 전체 지출 한도는 아닙니다.

## 6. 보고서 읽기

실제 실행 후에만 집계 보고서를 생성합니다. 만료·철회·동의 변경·삭제된 실행은 보고서 생성을 거부합니다.

```powershell
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-report --name vision-pilot-001 --comparison-run paired-001
```

개별 결과·시도 기록은 비공개 실행 폴더에, 집계는 `summary.json`과 한국어 `summary.md`에 저장합니다. 집계에는 개인별 사진 ID·참여자 ID·파일명이 포함되지 않습니다. 원본이나 정제 사진을 보고서에 넣지 않습니다.

- 전체 대상 수를 분모로 완료·거절·실패·미기록/중단을 보여줍니다. 응답을 받았지만 판단 불가인 사진은 별도의 관찰 건수로 확인합니다. 완료가 정답을 뜻하지 않습니다.
- 시간은 기록된 요청의 중앙값과 p95이며 로컬 모델 초기 로딩은 실행 설정에 별도로 남습니다.
- 비용은 실제 응답의 입력·출력 토큰과 2026-10-11 확인한 표준 비캐시 요금(각 100만 토큰당 USD 0.40/1.60)을 사용한 추정입니다. API 사용량에 이미지 비용이 이미 포함되므로 이미지 배수를 다시 곱하지 않습니다. 캐시·세금·다른 요금제와 청구 차이가 있을 수 있습니다. 응답이나 사용량이 없는 요청은 무료로 간주하지 않습니다. [모델 요금 문서](https://developers.openai.com/api/docs/models/gpt-4.1-mini)를 실제 실행 전에 재확인하세요.
- 반복 일치는 참여자별 사진 쌍의 완전 일치 비율을 구한 뒤 참여자 그룹에 같은 가중치를 줍니다. OpenAI는 다섯 항목 모두 보임/보이지 않음인 출력만 이 계산에 사용하며 불확실·판단 불가 건수는 따로 남깁니다. ConvNeXt는 8개 코드, OpenAI는 5개 관찰을 비교하므로 차원과 포함되는 사진 쌍이 달라 두 비율을 직접 비교할 수 없습니다. 조명이나 촬영이 바뀌면 실제로 보이는 특징도 달라질 수 있습니다. **반복 일치는 정확도가 아닙니다.**

코드 의미와 독립 기준이 없는 현재 보고서의 우승 모델은 항상 미정입니다. 모델끼리의 일치나 주관적인 설명 선호만으로 운영 모델을 교체하지 않습니다.

## 7. 정확도 비교를 위한 다음 관문

1. 데이터 제공기관에서 코드 정의, 평가자 기준, 항목별 적합 사진 부위를 확인합니다. GPT의 다섯 육안 항목과 비교 가능한 공통 정의·예시를 사람이 검토해 고정합니다. 확인이 불가능한 항목은 공통 정확도 평가에서 제외합니다.
2. 최소 두 명의 훈련된 평가자가 모델 출력을 보기 **전에** 사진만 보고 독립적으로 라벨을 붙이고 기록을 잠급니다. 불확실·판단 불가와 원인을 따로 남긴 뒤 불일치를 조정합니다. ChatGPT 결과를 ConvNeXt의 정답으로 사용하지 않습니다.
3. 동일 참여자의 모든 촬영은 한 그룹·한 분할에 둡니다. 파일럿으로 기준이나 프롬프트를 바꿨다면 새로운 참여자의 독립 테스트를 마련합니다. A/B 순서만 가려도 코드와 문장 형태가 달라 방식이 드러날 수 있으므로 사진 기준 평가를 먼저 합니다.
4. 공통 기준이 검증된 항목에만 정확도·혼동표·클래스별 지원 수를 계산합니다. 불확실/판단 불가 비율과 전체 운영 실패율을 조건부 정확도 옆에 제시하고, 표본에 없는 클래스는 미측정으로 표시합니다. 후속 신뢰구간은 사진이 아닌 참여자 그룹을 재표집합니다. 현재 도구는 이 정확도 계산을 구현하거나 실행하지 않습니다.
5. 성능·비용·시간·프라이버시와 매장 촬영 조건을 함께 보고 제공업체를 선택합니다. 육안 특징 평가가 좋더라도 성분 효능·알레르기 안전성이나 추천의 정확도를 입증하지 않습니다. 운영 전송 동의·API 계약과 기존 추천 입력 계약은 별도의 검토가 필요합니다.

## 8. 만료·철회·정리

동의 철회 시 `consents.json`의 해당 `revoked_at`을 실제 UTC 시각으로 기록하고 바로 정리 명령을 실행하세요. 만료된 결과도 같은 명령으로 정리합니다. 현재는 운영자가 실행하는 명령이며 자동 삭제 작업이 예약돼 있지 않습니다.

```powershell
& "C:\Projects\AELUNE\scripts\ml.ps1" comparison-purge --name vision-pilot-001
```

현재 동의가 철회·만료되었거나 실행 보관 기한이 만료된 경우 해당 평가 실행의 개별 결과·시도 기록·생성 보고서를 삭제하고 재사용 방지용 삭제 표시를 남깁니다. 보수적으로 같은 평가의 다른 참여자 결과까지 정리될 수 있습니다. 생성 시각·버전·집계 설정은 남을 수 있습니다. **직접 넣은 원본 사진, 사진 목록, 동의 증빙은 이 명령이 삭제하지 않습니다.** 운영자가 동의 범위와 보관 정책에 따라 정확한 파일을 별도로 삭제해야 합니다. 백업·동기화와 외부 제공업체 보관 정책도 별도로 관리하세요.

기한 전 실험을 정리하거나 동의 파일이 누락·손상돼 일반 정리를 할 수 없다면 `comparison-purge --name vision-pilot-001 --all-results`로 해당 평가의 생성 결과 전체를 명시적으로 삭제할 수 있습니다. 원본 사진은 여전히 별도로 관리합니다. 삭제한 실행 이름은 다시 사용하지 않습니다.

삭제와 결과 저장은 같은 실행별 운영체제 잠금을 사용합니다. 먼저 삭제 표시를 디스크에 기록한 뒤 결과를 제거하므로 진행 중인 요청·보고서 생성이 결과를 다시 만들 수 없고 이후 사진의 새 시도도 차단됩니다. 잠금은 네트워크 처리 중에는 잡지 않습니다. 이미 시작된 외부 시도는 비용이나 외부 보관이 발생할 수 있습니다.
