# 전체 자료 확장 학습 결과

2026-10-11, 사용자의 요청으로 이 PC에서 압축 해제, 두 모델의 실제 학습, 저장된 최선 모델의 재평가를 완료했습니다. 이는 최초의 확장 실험 결과이며 독립 테스트나 매장 환경의 제품 정확도가 아닙니다. 실행 명령과 비공개 저장 위치는 [한국어 학습 가이드](../ml/README.md)에 있습니다.

## 사용한 자료

모공·미백·개방데이터를 포함한 등록 원본의 ZIP 29개를 전부 해제하고, 이미 풀려 있던 자료도 복사했습니다. 총 CSV 9,000개, JPG 9,000장, 추천 JSONL 9,000건과 성분 XLSX 1개, 합계 27,001개 파일(7,747,717,918바이트)입니다. 원본을 이동하거나 수정하지 않았으며 작업 결과는 OneDrive 밖의 비공개 학습 폴더에 보관했습니다.

| 실험              | 원래 학습 / 검증 자료 | 정리 후 학습 / 검증 | 실행                                   |
| ----------------- | --------------------: | ------------------: | -------------------------------------- |
| 피부사진 8개 항목 |       8,000 / 1,000장 |       1,980 / 123장 | `skin-all-head-001`, GPU 5에포크       |
| 성분 후보 54개    |       8,000 / 1,000건 |       5,891 / 478건 | `ingredients-linear-001`, CPU 20에포크 |

사진은 동일 바이트의 사진 695개 그룹이 학습·검증 양쪽에 있어 양쪽에서 모두 제외했습니다. 같은 분할의 중복도 정리했습니다. 검증 사진을 학습으로 옮기지 않았습니다. 보존된 사진의 상·중·하 부위 수는 학습 188/1,516/276장, 검증 23/79/21장입니다.

성분 자료는 양쪽에 겹치는 동일 프로필·동일 모델 입력 429개 그룹을 제외했습니다(학습 1,198건, 검증 490건). 성분 이름을 찾을 수 없는 답변, 지원 빈도가 부족한 후보와 동일 프로필·정답의 중복도 정리했습니다. 남은 학습 5,891건은 서로 다른 구조화 프로필 4,824개, 검증 478건은 466개에 해당하며 검증된 사람 수를 뜻하지 않습니다.

## 피부사진 모델

ImageNet으로 사전 학습된 ConvNeXt-Tiny 특징 추출부는 고정하고, 8개 분류 출력층을 학습했습니다. 배치 8, 학습률 0.001, 시드 42로 모든 학습 사진을 에포크마다 처리했습니다. 비어 있거나 충돌하는 정답은 항목별로 제외하는 구조이며, 이번 실제 자료에서는 충돌이 발견되지 않았습니다. 여드름 정답은 학습 101장과 검증 10장에서 비어 있습니다.

8개 항목의 balanced accuracy 평균을 기준으로 **에포크 4**의 체크포인트를 선택했습니다. 평균은 **75.79%**이며, 학습에서 가장 많은 코드만 항상 예측하는 기준 모델은 **45.83%**입니다. 항목 간 단순 평균이며 모든 피부 상태를 종합한 개인 점수는 아닙니다.

| CSV 평가 항목 | 코드         | 정답이 있는 검증 사진 | Balanced accuracy | Macro F1 |
| ------------- | ------------ | --------------------: | ----------------: | -------: |
| 민감성        | NS / S       |                   123 |            62.02% |   0.5269 |
| 미백          | P0 / P1 / P2 |                   123 |            88.89% |   0.7516 |
| 주름          | W0 / W1 / W2 |                   123 |            77.53% |   0.7287 |
| 여드름        | NA / A       |                   113 |            76.51% |   0.7592 |
| 모공          | NVP / VP     |                   123 |            81.56% |   0.8056 |
| 피부 처짐     | NSA / SA     |                   123 |            81.08% |   0.7941 |
| 과각질        | ND / D       |                   123 |            69.96% |   0.5804 |
| 붉어짐        | NR / R       |                   123 |            68.76% |   0.6039 |

Balanced accuracy는 각 코드의 재현율을 동일하게 평균합니다. Macro F1은 각 코드의 정밀도와 재현율을 함께 반영한 F1의 평균입니다. 코드 의미·순서·평가자와 사진 부위별 적합성이 아직 확인되지 않아 이를 의학적 진단이나 심각도 측정으로 해석할 수 없습니다. 과각질 D 코드는 학습 35장, 검증 4장뿐이어서 해당 지표가 특히 불안정합니다. 이전 모공 전용 `head-001`의 검증 79장과 이번 123장은 구성이 다르므로 두 점수를 직접 성능 개선률로 비교하지 않습니다.

## 성분 후보 모델

피부 타입·상태·고민·연령대·성별·외부 요인의 구조화 입력을 2,048차원 특징으로 변환하는 다중 라벨 선형 모델입니다. 질문·답변·추론 설명·이미지 파일명·원본 ID는 입력에서 제외했습니다. 답변은 INCI/한글 성분 사전으로 자동 정답 후보를 추출할 때만 사용했습니다. 모호한 이름, 명시적인 부정 문맥과 다른 화합물 이름 안의 짧은 성분명을 잘못 매칭하지 않도록 처리했습니다.

성분 사전은 2,465개 INCI 이름과 4,890개 별칭을 포함합니다. 학습 분할의 서로 다른 프로필 10개 이상에서 관찰된 54개 후보를 학습했습니다. 배치 64, 학습률 0.01, 시드 42, 임계값 0.5이며 검증 micro F1을 기준으로 **에포크 16**의 모델을 선택했습니다.

| 지표                 | 학습 모델 | 학습 자료의 빈출 성분 5개만 추천하는 기준 |
| -------------------- | --------: | ----------------------------------------: |
| Micro F1, 임계값 0.5 |    0.6875 |                                         — |
| 상위 5개 정밀도      |    60.54% |                                    22.59% |
| 상위 5개 재현율      |    82.19% |                                    35.56% |

상위 5개 정밀도는 예측한 5개 후보 중 자동 정답과 일치하는 비율의 레코드 평균이고, 재현율은 자동 정답 후보 중 상위 5개가 찾은 비율의 레코드 평균입니다. 검증에는 54개 중 52개 후보가 등장하고, 14개 후보는 검증 정답 5건 미만입니다. 따라서 모든 성분의 성능이 확인된 것은 아닙니다.

자동 추출 정답은 전문가가 승인한 효능·안전성 정답이 아닙니다. 답변에 언급되지 않은 성분도 부적합 성분을 의미하지 않습니다. 이 모델은 성분 후보를 제안하는 연구용이며 함량·치료 효과·사용 루틴의 적절성을 검증하지 않습니다. 사진·CSV와 추천 JSONL의 개별 연결이 확인되지 않아 두 모델을 별도로 학습했으며, LLM을 학습하거나 외부 AI API로 자료를 전송하지 않았습니다. 이후의 사진 코드 전달은 원천 범주의 구조 호환을 이용한 추론 연결이며, 새로운 통합 모델 학습이나 정답 연결이 아닙니다.

## 저장과 검증

두 모델의 최선 체크포인트를 별도 명령으로 다시 불러와 검증했습니다. 사진 모델의 모든 혼동 행렬·지표·손실과 성분 모델의 지표가 학습 당시 기록과 정확히 일치했습니다. 이는 저장 모델의 결과 재현 확인이며 다른 PC에서 재학습한 가중치까지 동일하다는 보장은 아닙니다.

재평가 전후 SHA-256 비교에서 두 모델의 모든 원래 학습 결과 파일이 보존됐고, 확장 작업 전후 기존 `head-001`의 두 체크포인트·설정·지표도 동일했습니다. 평가는 고유한 비공개 폴더에 집계 보고서만 추가합니다. 원본 사진·설문·레코드 ID와 개별 예측은 이 문서나 Git에 넣지 않았습니다.

전체 ML 테스트는 **322개와 하위 테스트 20개 통과**, Windows 권한이 필요한 원본 심볼릭 링크 생성 테스트 1개는 건너뛰었습니다. 악성 ZIP 경로·심볼릭 링크 거부 테스트는 통과했습니다. 테스트에는 합성 데이터 학습, 누락 라벨 처리, 입력 누출 방지, 중복 제외, 저장 모델 재평가, 결과 보존과 오류의 개인정보 제한이 포함됩니다.

학습 완료 당시 키오스크는 모의 분석이었습니다. 이후 사용자의 명시적 요청으로 저장된 두 모델을 **실험용 로컬 키오스크 모드**에 연결했습니다. 사진은 메모리에서만 처리합니다. [원천 코드 입력 계약](ML-SOURCE-CODE-CONTRACT.md)은 8개 사진 코드와 추천 JSONL의 `initial_skin_condition` 사이의 범주·직렬화 구조를 확인하며, 코드의 임상 의미나 개별 사진·설문 연결은 입증하지 않습니다.

추천 JSONL 9,000건과 원래 매니페스트의 원천 지문을 대조하고, 보존된 TRAIN 프로필 4,824개를 확인해 전체 상태 범주 145개의 비공개 지원 파일을 별도로 준비했습니다. 사진 출력은 이 순서의 전체 문자열을 기존 정규화·해시로 바꾸며, 지원 파일에 있는 조합만 설문 입력과 함께 후보 순위에 반영합니다. 학습에 없던 조합은 표시 후 제외하여 설문 입력만 사용합니다. `visual_condition_used_source_contract_v1` 또는 `visual_condition_unseen_in_training_omitted`가 실제 사용 여부를 기록하고, 전체 분석 버전의 `:source-codes-v1`이 이 입력 정책을 구분합니다. 원래 가중치·매니페스트·학습 지표를 바꾸거나 재학습하지 않았습니다.

후보 순위는 검토된 매장 정책·전성분·재고·제외 조건을 통과한 제품에만 반영됩니다. 선택한 피부 타입·고민·민감도와 제외 성분은 사진 코드로 바꾸지 않습니다. 위 학습 지표는 이 부분 입력과 사진→제품 전체 경로의 정확도가 아닙니다. 코드의 임상 정의·평가자 확인, 사람 단위 분리와 근접 중복 점검, 잠근 독립 테스트와 실제 매장 카메라 검증은 여전히 필요합니다. [키오스크 모델 연결 가이드](KIOSK-MODEL-SETUP.md)를 참고하세요.
